# حسبة 1.0.0

تطبيق Flutter لحساب ألعاب الورق والدومنة بواجهة عربية RTL وهوية داكنة/ذهبية.

## ما تم تثبيته في هذه النسخة
- أسماء اللاعبين ليست ثابتة: يمكن تعديل اسم **كل لاعب** قبل بدء اللعبة.
- الاسم المعدل ينتقل تلقائياً إلى تسجيل النقاط والترتيب والسجل والإحصائيات.
- دعم 2–8 لاعبين.
- 3 / 5 / 7 / 10 جولات.
- قاعدة الورق: 0 = -25 تلقائياً.
- تراجع عن آخر جولة.
- حفظ الألعاب تلقائياً على الجهاز.
- سجل الألعاب مع حذف بالسحب.
- إحصائيات وعدد الانتصارات.
- اسم التطبيق: **حسبة**.
- أيقونة تطبيق داكنة/ذهبية متناسقة مع هوية حسبة.

## Android
```bash
flutter create .
flutter pub get
dart run flutter_launcher_icons
flutter build apk --release
```

## iOS
```bash
flutter pub get
dart run flutter_launcher_icons
flutter build ios --release
```

> بناء iOS النهائي يحتاج macOS + Xcode، وبناء APK يحتاج Android SDK.

- تحديث واجهة تسجيل النقاط لتقترب من التصميم المرجعي: لوحة وسطية، لوحات جانبية للشاشات العريضة، ترتيب أوضح، وانتقالات/حركات خفيفة عند تبدّل الجولة والنقاط.
